## Overview

Digital Clock is a simple browser-based project that displays the current time using JavaScript. HTML defines the page structure, CSS controls the presentation, and JavaScript updates the clock dynamically.

## Live Demo

**Try it here:** [Digital Clock — Live Website](https://rabadejanhvi-45.github.io/clock.github.io/)

## Features

- Displays the current time in the browser.
- Updates the time dynamically using JavaScript.
- Uses a custom CSS layout and styling.
- Runs directly in a web browser without a backend server.

## Technology Stack

| Technology | Purpose |
|---|---|
| HTML5 | Structures the webpage |
| CSS3 | Styles the clock and page layout |
| JavaScript | Retrieves and updates the time |
| GitHub Pages | Hosts the static website |

## Project Structure

```text
clock.github.io/
├── index.html   # Webpage structure
├── style.css    # Styling and layout
├── script.js   # Clock logic and time updates
└── README.md   # Project documentation
```

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/RabadeJanhvi-45/clock.github.io.git
   ```

2. Open the cloned project folder.
3. Open `index.html` in your browser.

No backend, database, or package installation is required for the described static project.
